Chargeur : 3 variantes

Il n'apparaît que si une page attend la base plus de 250 ms (une lecture rapide ne montre rien) et reste au moins 400 ms (pas de clignotement). Pendant ce temps, la page montre déjà sa forme (squelettes). Tout est en CSS (transform / opacity) : il reste fluide même quand le téléphone est occupé à construire la page qui arrive. Mouvement réduit : le logo reste immobile.

Pour changer : src/config/apparence.js → CHOIX.chargeur = 'pastille' | 'tempo' | 'anneau' (une seule ligne). Variante appliquée en provisoire : pastille.

Aperçu animé des trois (si la page est ouverte sans les feuilles de style) : variantes.webp · capture fixe : variantes.jpg.
